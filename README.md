# Конверты — семейный бюджет

Приложение для бюджета по системе конвертов (фондов). Работает без интернета и ставится на домашний экран.
Данные хранятся только в браузере на телефоне: на сервер ничего не отправляется.

## Как выложить на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на https://github.com и нажмите **New repository**. Название, например, `konverty`, тип **Public**, затем **Create**.
2. На странице репозитория нажмите **uploading an existing file** и перетащите **все файлы из этой папки вместе с папкой `icons`**. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В Source выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт заработает по адресу `https://ВАШ_ЛОГИН.github.io/konverty/`.

## Установка на телефон
- **iPhone:** откройте адрес в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** Chrome → ⋮ → «Добавить на главный экран».

## Важно
- Регулярно делайте резервную копию: Ещё → Данные → «Сохранить копию». Если очистить данные Safari, всё пропадёт.
- У каждого телефона свои данные. Чтобы перенести их на другое устройство, сохраните копию на одном и загрузите на другом.
- Чтобы выпустить обновление, загрузите изменённые файлы в репозиторий заново. Если меняете файлы, увеличьте номер в `sw.js` (`konverty-v1` → `v2`).
